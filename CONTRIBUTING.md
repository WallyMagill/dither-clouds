# Contributing

Thanks for helping improve Dither Clouds.

1. Open an issue for substantial changes so the direction is clear.
2. Fork the repository and create a focused branch.
3. Keep the renderer dependency-light and preserve the CSS fallback, reduced-motion behavior, framebuffer cap, and React-free engine boundary.
4. Run `npm test`, `npm run lint`, and `npm run build`.
5. Open a pull request describing the visual or technical change. Include a screenshot for shader, palette, or control changes.

By contributing, you agree that your work is licensed under the repository's MIT license.
