# Security Policy

Dither Clouds is a client-only visual component with no backend, accounts, or stored user data. If you find a security issue in the renderer, dependency setup, or demo, please report it privately through [GitHub's private vulnerability reporting](https://github.com/WallyMagill/dither-clouds/security/advisories/new).

Please include affected files or versions, reproduction steps, impact, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability.
